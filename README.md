# CCNA & Enterprise Networking Labs

Hands-on Cisco Packet Tracer labs by **Junior Nemoh Asong Egbe**, Network & Security Engineer (Buea, Cameroon).

- 75 CCNA labs covering switching, routing, security, IPv6, WAN/VPN, wireless, VoIP and Cisco ASA firewalls
- Enterprise network design projects, including a healthcare case study

**To open the labs:** install [Cisco Packet Tracer](https://www.netacad.com/cisco-packet-tracer) (free with a Cisco Networking Academy account), then open any `.pkt` file.
